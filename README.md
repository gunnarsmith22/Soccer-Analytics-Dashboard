# Soccer Analytics Dashboard

## Overview
This project uses Python to analyze soccer player and team statistics. It focuses on identifying trends in player performance, including goals, assists, shots, and other statistics.

The goal of this project is to organize soccer data, analyze performance, and present the results in a way that makes them easier to understand.

## Technologies Used
- **Python** – Main programming language
- **Pandas** – Data cleaning and analysis
- **Matplotlib** – Creating charts and visualizations
- **PostgreSQL** – Storing and querying soccer statistics

## Features
- Analyzes soccer player and team statistics.
- Tracks performance metrics such as goals, assists, and shots.
- Uses Pandas to organize and analyze data.
- Creates visualizations to display trends and comparisons.
- Uses PostgreSQL to store and query data.

## Skills Demonstrated
- Python programming
- Data analysis and manipulation
- Data visualization
- SQL and database management
- Problem-solving and analytical thinking

## Purpose
This project was created to practice working with data and explore how programming can be used to analyze soccer performance. It combines database management, Python programming, and data visualization into one project.
