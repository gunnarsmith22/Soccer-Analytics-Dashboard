# Soccer Analytics Dashboard

## Overview
This project uses Python to analyze soccer player and team statistics. It focuses on identifying trends in player performance, including goals, assists, shots, and other statistics.

The goal of this project is to organize soccer data, analyze performance, and present the results in a way that makes them easier to understand.

> **Note:** The included dataset in `/data` is **fictional sample data** generated by `generate_sample_data.py` so the project runs out of the box. Replace the CSVs with real data (same column names) to analyze real players and teams.

## Technologies Used
- **Python** – Main programming language
- **Pandas** – Data cleaning and analysis
- **Matplotlib** – Creating charts and visualizations
- **PostgreSQL** – Storing and querying soccer statistics (via SQLAlchemy)

## Features
- Analyzes soccer player and team statistics across multiple seasons
- Tracks performance metrics such as goals, assists, shots, and shot accuracy
- Calculates per-90-minute metrics, conversion rate, and goal contributions
- Creates visualizations for rankings, team comparisons, and trends over time
- Stores data in PostgreSQL with a relational schema (`teams`, `players`, `player_stats`)
- Works without a database too: CSV mode runs with just pandas and matplotlib

## Getting Started

### 1. Install
```bash
git clone https://github.com/<your-username>/soccer-analytics-dashboard.git
cd soccer-analytics-dashboard
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Run with CSV data (no database needed)
```bash
python main.py
```
This prints summary tables and saves charts to `/charts`.

### 3. Run with PostgreSQL
1. Create a database: `createdb soccer_db`
2. Copy `.env.example` to `.env` and set your `DATABASE_URL`
3. Create the tables and load the data:
   ```bash
   python main.py --init-db
   ```
4. From then on, analyze straight from the database:
   ```bash
   python main.py --source postgres --season 2024
   ```
